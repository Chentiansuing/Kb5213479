## What's New

### 15.1 — Quality Update
**Fixed**
- Dark mode: Settings text is now readable (dark theme variables and hard-coded colors corrected).
- Taskbar and tray icons are no longer inverted by the legacy dark-mode filter.
- Toggle switch thumb no longer overflows the track in the "on" state.
- Notification center no longer shows "No new notifications" while notifications exist; the empty state returns after clearing.
- Dark-mode scrollbars are now translucent instead of bright white.

**Added**
- Task Manager: new **Startup** tab with four startup apps, impact level (High/Medium/Low) and per-app enable/disable.
- Clipboard history: **pin** an entry to the top and **delete** individual entries (kept for the session).
- Settings search: shows "No matching settings" when nothing matches.

### 15.0 — System Tools
- **Task Manager**: Processes and Performance tabs, app and system processes, live CPU/memory/disk/network charts, end task.
- **Clipboard history** (Ctrl+Shift+V): records copied text, click to copy again, up to 12 entries.
- **Storage Sense**: scans temporary files, Recycle Bin and update cache, then cleans them with a progress animation.
- **Focus assist**: 25-minute countdown, suppresses toasts while active, auto-restores when finished.
- **Settings search**: filters the navigation list live, Enter jumps to the first match, Esc clears.
- **Keyboard shortcut guide**: hold Win or click the version badge to open it.
- **Dynamic theme**: derives the accent color from the wallpaper and switches dark/light by time of day.
- **Install report export**: saves edition, device, partition and duration as Markdown from the finish page.
- **Notification cleanup**: unread dot, mark as read on open, clear all at once.

### 14.0 — Interface Rewrite
- Rewrote the visual language of dialogs, forms, the install page, OOBE and the desktop shell.
- New motion system: spring easing, staggered entrances, window scale-in, page cross-fade, dock-style taskbar magnification, pointer parallax and button ripples.
- New Fluent icon pack (inline SVG sprite) across desktop, Start, taskbar, tray and title bars.
- Performance pass: lower backdrop blur radii, `contain: layout paint` on overlays, passive and rAF-throttled pointer events, and animations paused while the page is hidden.
- Reduced-motion option in Settings > Personalization, plus OS `prefers-reduced-motion` support.

### Earlier
Versions 3.0–13.0 added the multi-language installer, OOBE, desktop environment, built-in apps, camera recording, local-time-aware apps, and per-version documentation pages.
