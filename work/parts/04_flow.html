10.0 有什么新功能

以下是 10.0 与 9.0 版本的新增内容。

10.0 新增
安装助手：随步骤变化的智能建议右下角助手按钮会根据当前页面给出操作提示，并提供常用工具入口。
性能监视器：CPU / 磁盘 / 网络实时曲线安装页可展开性能面板，观察安装期间三类资源的占用变化。
Wi-Fi 扫描与密码连接OOBE 网络页支持重新扫描、发现新网络并输入网络安全密钥。
安装配置导出 / 导入把版本、设备名、分区与选项保存为 JSON，下一次一键复用。
成就系统：8 枚可解锁徽章完成安装、无人值守、面部识别等操作会解锁徽章并弹出提示。
安装时间线回放记录每一步的进入时间与停留时长，可完整回放整个安装过程。
故障诊断中心选择症状后自动执行三步检查，给出结论与修复方案。
磁盘分区布局图磁盘页顶部以彩色色块展示分区占用，点击即可选中分区。
8.1 新增
启动欢迎页：立即安装、修复计算机、导入安装配置还原真实的 Windows 安装程序入口，可跳过检查直接安装，也提供修复工具入口。
系统还原点：安装前自动创建，可随时回滚在开始安装前创建还原点，安装失败也能回到当前状态。
设备加密：BitLocker / XTS-AES 询问与说明在 OOBE 阶段询问是否启用 BitLocker 设备加密，并提供恢复密钥备份说明。
标题栏安装进度：安装时标题实时显示百分比切换到其他标签页也能看到安装进度。
通知中心：版本更新与安装完成通知点击任务栏时钟即可查看最新通知。
8.0 新增
系统兼容性报告：8 项硬件检测与评分在检查系统要求页可查看 CPU、内存、显卡、磁盘、TPM 等详细信息。
辅助功能：讲述人、放大镜、高对比度与更大文字在 OOBE 阶段选择辅助功能，预览框实时显示效果。
Windows 更新检查：5 项更新逐个安装联网后自动检查累积更新、驱动与 Defender 定义。
实时安装日志：过滤、暂停、导出到 Temp安装过程中随时查看内部日志，便于排查问题。
深色模式：一键切换整套安装程序主题右上角月亮按钮切换浅色/深色，偏好自动记忆。
安装速度档位：标准 / 快速 / 演示演示模式 8 秒完成安装，适合录屏展示。
安装摘要：版本、设备、位置与耗时，可导出报告安装完成后一键导出完整安装报告到 Temp 目录。
9.0 新增
无人值守安装：应答文件一键装完开启后自动选择版本、分区并应答全部 OOBE 页面，带进度提示条。
安装源选择：ISO / USB / 网络不同来源记录不同日志，影响安装准备阶段的提示。
磁盘清理工具：安装前释放空间扫描 6 类可清理文件，勾选后即时释放空间。
Windows Hello 面部识别扫描动画模拟人脸录入，成功后进入 PIN 设置。
Microsoft 账户两步验证邮箱 → 密码 → 6 位验证码的完整登录链路（演示环境任意 6 位）。
软件推荐页：OEM 预装软件勾选5 个推荐软件可自由勾选或全部跳过。
首次开机动画安装完成后首次进入桌面播放全屏启动动画。
系统音效使用 Web Audio 合成点击、错误与完成提示音，可在快速设置中开关。
系统信息与更新历史运行 winver 查看版本信息，更新历史记录一键查看。
双系统启动菜单重启时概率出现“选择操作系统”菜单，含 Windows 10 条目。
动态通知推送安装完成与更新就绪会实时推送到通知中心。
